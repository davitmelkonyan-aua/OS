COMPILATION

The source files were compiled separately into object files:

gcc -c main.c -o main.o

gcc -c math_utils.c -o math_utils.o

The -c option creates relocatable object files without performing the final linking step. The object files were then linked:

gcc main.o math_utils.o -o square_prog

This creates the final executable square_prog.

The output shows that main.o contains the definition of main and a reference to square, while math_utils.o contains the definition of square. The linker resolves this reference when creating the final executable.

CONCLUSION

The compilation process creates separate relocatable object files from the individual C source files. nm can be used to inspect symbols and distinguish between definitions and unresolved references. objdump can display the machine instructions contained in the object files and final executable. readelf can be used to inspect the ELF headers and sections.

The output demonstrates that main.o contains a reference to square, math_utils.o contains the definition of square, and the linker resolves this reference when creating square_prog.
